Encontré dos bugs bien concretos:

1. El navigate no anda porque SideBar nunca recibe navigation

En Home.js lo estás llamando así:

jsx
<SideBar usuarioSesion={perfiles[0]} />

Nunca le pasás la prop navigation. Adentro de SideBar hacés navigation.navigate("Perfil"), así que navigation es undefined y al tocar "Profile" te tira un error (revisá la consola, seguro ves algo como "Cannot read property 'navigate' of undefined").

Solución: Home es una Stack.Screen, así que React Navigation le pasa automáticamente la prop navigation. Solo tenés que recibirla y reenviarla:

jsx
export default function Home({ navigation }) {
  // ...resto del código

  return (
    <SafeAreaView style={styles.appContainer}>
      <View style={styles.sidebar}>
        <SideBar usuarioSesion={perfiles[0]} navigation={navigation} />
      </View>
      {/* ... */}
    </SafeAreaView>
  );
}

Alternativa más prolija (recomendada): en vez de pasar navigation como prop manualmente por todos lados, usá el hook useNavigation() directo dentro de SideBar:

jsx
import { useNavigation } from '@react-navigation/native';

const SideBar = ({ usuarioSesion }) => {
  const navigation = useNavigation();
  // ...
  onPress={() => navigation.navigate("Perfil")}

Así no dependés de que cada pantalla se acuerde de pasarla.

2. El scroll no anda (esto es típico de React Native Web)

Tu ScrollView está bien configurado (flex:1 + contentContainerStyle con flexGrow:1), el problema casi seguro es que estás corriendo esto en web y el árbol de html/body/#root no tiene una altura definida. En React Native puro, flex:1 en la raíz siempre llena la pantalla porque el nativo maneja el layout con altura real del dispositivo. En web, si el body/html no tienen height: 100%, el flex:1 de tus View no tiene contra qué medirse, todo el árbol crece según el contenido, y el ScrollView nunca detecta que hay overflow → no aparece scroll.

Solución: agregá esto en tu index.html (o en el CSS global si usás Expo Web con web/index.html):

css
html, body, #root {
  height: 100%;
  margin: 0;
}

Si usás Expo, podés ponerlo en un archivo web/index.html propio, o si no lo tenés, corré:

npx expo customize:web

para generar ese archivo y editarlo.

Cómo confirmar que es esto: abrí las devtools del navegador, inspeccioná el <div id="root"> y fijate si su altura es mayor a la del viewport (o sea, se está estirando con el contenido en vez de quedar fija). Si es así, es 100% este problema.

Si estás probando en un emulador/dispositivo real (no web) y el scroll tampoco anda ahí, contame y reviso otra cosa — pero por el layout que armaste (flexDirection: row con sidebar fijo tipo web) intuyo que estás corriendo esto en Expo Web.
